# 已知问题与未决事项

1. **Ubuntu 实机验收未完成。** 完整恢复、保留数据升级、SeaDoc 和重启持久性仍待验证。本次工作只证明了归档重建、静态配置与工具行为。
2. **GitHub 不保存业务素材。** 本机独立素材库和 Downloads 原包都位于同一台电脑，尚无异机/异盘副本证据。同一磁盘上的多份副本不能抵抗整机丢失。
3. **不含运行时离线介质。** Docker/Compose 与系统工具需另行提前准备；裸机完全离线一键装系统不在当前交付范围。
4. **备份一致性不能从哈希推导。** 原包中的物理数据库与卷恢复须实机验收；保留源环境。
5. **历史版本较固定。** 不主动换组件版本；安全维护或跨版本升级需要单独规划与验收。
6. **HTTP 与固定路径。** 本基线没有新增 HTTPS、通用数据根目录或其他 CPU 平台的支持。
7. **素材在本机未加密。** Git 忽略规则和内容寻址不提供保密性；搬运、远程备份须使用受控/加密存储，不公开上传。
8. **外层打包需要支持硬链接的文件系统。** 现实现使用原子硬链接发布对象及归档（NTFS/ext4 支持）；exFAT/FAT 可搬运完成品，但不作为 capture/pack 工作目录。
9. **历史原安装器未作逻辑审计升级。** Bash/Compose 静态检查不覆盖中断恢复、数据一致性、升级失败与网络隔离启动；须在独立环境演练。

以上事项在解决并附证据之前保留在交接文件中。
