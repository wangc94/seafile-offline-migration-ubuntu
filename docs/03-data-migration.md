# 首次完整恢复

此模式面向空目标环境，将备份时点的全部业务恢复过去。它不用于覆盖正在运行的数据库。

1. 先校验外层交付 TAR，再解出整个包并校验 `SHA256SUMS`。
2. 确认目标挂载目录、同名容器、网络和卷没有需要保留的内容。安装器会检查冲突，但操作者仍需确认目标机身份。
3. 执行 `sudo bash ./install.sh`，选择 1，输入固定 IP、端口和时区并核对摘要。
4. 安装器导入归档镜像并核对身份，解出配置、MariaDB、Seafile、ONLYOFFICE、字体、Caddy 和补丁备份。
5. 创建并恢复 ONLYOFFICE 三个具名卷，保持 RabbitMQ 原 hostname；SeaDoc 此基线按首次启用创建持久化目录。
6. 应用目标配置、按顺序启动，执行自动检查与人工验收。

数据库备份为物理 TAR，不是 SQL 逻辑转储。归档一致性依赖原备份时是否正确停服；本次 SHA256 验证只能证明字节一致，不能证明源数据库当时的事务一致性。保留原 Windows/WSL 环境，直到业务与重启验收完成。

解包中断后会保留 staging 和阶段标记；原包内的 `install.sh` 使用包身份避免中途替换输入。排查应结合阶段标记、日志、目录与卷内容，不自动删除半恢复数据。
